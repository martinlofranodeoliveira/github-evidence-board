# Changelog

## 0.1.0 — Unreleased

Development version with an explicit snapshot and report contract.

### Added

- Pure ES module validation and normalization with bounded payloads and exact field diagnostics.
- Six conservative CI evidence verdicts, explicit evaluation time/TTL and source-SHA coverage across active workflows.
- Static browser workbench with synthetic data, local editor/import, intersecting filters, detail dialog and deterministic JSON/Markdown audit export.
- Explicit unauthenticated public GitHub refresh with fixed endpoints, bounded inventory/run pagination, response limits and failure preservation.
- Offline Node CLI, loopback preview server and synthetic regression/adversarial tests.
- English and Brazilian Portuguese usage documentation, contract, design rationale and security reporting instructions.

### Scope

Imported provenance is not authentication. Verdicts concern a documented subset of point-in-time GitHub Actions metadata; they are not quality, security, compliance or commercial eligibility certifications. No runtime credentials, telemetry, automatic refresh, publishing or deployment automation are included.

- Preserve runtime collector evidence across normalization while JSON imports stay unverified; document explicit assertion contexts and nonportable session marks.
- Include evidence basis/source SHA in Markdown reports and deeply freeze already-frozen collector records.
- Ignore obsolete refresh/file outcomes, preserve unapplied drafts, update open detail consistently and keep error focus within the dialog.
- Record source-only interface verification and use one-pixel semantic accent borders; rendering remains unverified.
